#+TITLE: acad-help-parser: Nyxt integration
#+AUTHOR: mna

* Назначение

Интеграция =acad-help-parser= с Nyxt позволяет загружать JavaScript-зависимые страницы Autodesk Help, получать фактический DOM после выполнения сценариев и разбирать ActiveX-документацию через Plump.

Рабочая цепочка:

#+begin_example
Emacs / SLY
    |
    v
Slynk :4008
    |
    v
Nyxt
    |
    v
JavaScript / DOM
    |
    v
fetch-dom-with-nyxt
    |
    v
Plump
    |
    v
parse-activex-class-document
#+end_example

* Подключение Emacs/SLY к Nyxt

** Запуск встроенного REPL Nyxt

В Nyxt:

#+begin_example
Ctrl+Space
repl
#+end_example

** Запуск Slynk

В REPL Nyxt:

#+begin_src lisp
(progn
  (asdf:load-system :slynk)
  (slynk:create-server :port 4008 :dont-close t))
#+end_src

Проверка порта из терминала:

#+begin_src sh
ss -ltnp | grep 4008
#+end_src

Ожидается слушающий сокет процесса =nyxt= на =127.0.0.1:4008=.

В Emacs:

#+begin_example

Port: 4008
#+end_example

После подключения REPL должен иметь приглашение:

#+begin_example
NYXT-USER>
#+end_example

Проверка:

#+begin_src lisp
(nyxt:current-buffer)
#+end_src

* Работа с DOM Nyxt

** Текущий буфер

#+begin_src lisp
(nyxt:current-buffer)
#+end_src

Проверка заголовка страницы:

#+begin_src lisp
(nyxt:ffi-buffer-evaluate-javascript
 (nyxt:current-buffer)
 "document.title")
#+end_src

** Поиск буфера по заголовку

#+begin_src lisp
(acad-help-parser:find-buffer-with-nyxt
 "Help: Ellipse Object (ActiveX)")
#+end_src

** Получение и разбор ActiveX-класса

Из конкретного буфера:

#+begin_src lisp
(acad-help-parser:fetch-activex-class-with-nyxt
 (nyxt:current-buffer)
 :wait t
 :timeout 60)
#+end_src

По URL:

#+begin_src lisp
(acad-help-parser:fetch-activex-class-with-nyxt-url
 "https://help.autodesk.com/view/ACD/2015/ENU/?guid=GUID-85D3077C-DAE6-4BB7-BB69-E8A8BD10FEA5"
 :wait t
 :timeout 60)
#+end_src

Для Autodesk Help поддерживаются обе обнаруженные структуры DOM:

#+begin_example
2015/2016:
  document -> #ui-content-frame -> .referencebody-adsk

2017:
  document -> .referencebody-adsk
#+end_example

Для страниц, где =meta[name="topicid"]= отсутствует, GUID берётся как fallback из =document.location.href=.

* Управление буферами Nyxt

Создать новый буфер по URL и сделать его текущим:

#+begin_src lisp
(defparameter *buffer*
  (nyxt:make-buffer-focus
   :url (nyxt:url
         "https://help.autodesk.com/view/ACD/2015/ENU/?guid=GUID-85D3077C-DAE6-4BB7-BB69-E8A8BD10FEA5")))
#+end_src

Проверка:

#+begin_src lisp
(eq *buffer* (nyxt:current-buffer))
#+end_src

Закрыть текущий отображаемый буфер:

#+begin_src lisp
(nyxt:delete-current-buffer)
#+end_src

** Получение DOM

DOM верхнего документа:

#+begin_src lisp
(nyxt:ffi-buffer-evaluate-javascript
 (nyxt:current-buffer)
 "document.documentElement.outerHTML")
#+end_src

DOM старого Autodesk iframe:

#+begin_src lisp
(nyxt:ffi-buffer-evaluate-javascript
 (nyxt:current-buffer)
 "document.getElementById('ui-content-frame').contentDocument.documentElement.outerHTML")
#+end_src

Через API проекта:

#+begin_src lisp
(defparameter *html*
  (acad-help-parser:fetch-dom-with-nyxt
   (nyxt:current-buffer)
   :iframe "#ui-content-frame"
   :wait t
   :timeout 60))
#+end_src

Разобрать HTML через Plump:

#+begin_src lisp
(defparameter *document*
  (plump:parse *html*))
#+end_src

** Диагностика структуры Autodesk Help

Проверить старый iframe:

#+begin_src lisp
(nyxt:ffi-buffer-evaluate-javascript
 (nyxt:current-buffer)
 "document.getElementById('ui-content-frame') !== null")
#+end_src

Проверить наличие тела ActiveX-статьи в основном DOM:

#+begin_src lisp
(nyxt:ffi-buffer-evaluate-javascript
 (nyxt:current-buffer)
 "document.querySelector('.referencebody-adsk') !== null")
#+end_src

Проверить =topicid=:

#+begin_src lisp
(nyxt:ffi-buffer-evaluate-javascript
 (nyxt:current-buffer)
 "document.querySelector('meta[name=\"topicid\"]')?.content")
#+end_src

Для новых страниц, где =topicid= отсутствует, проверить URL:

#+begin_src lisp
(nyxt:ffi-buffer-evaluate-javascript
 (nyxt:current-buffer)
 "document.location.href")
#+end_src
