#+TITLE: acad-help-parser
* Load
#+begin_src lisp
(ql:quickload :acad-help-parser)
#+end_src
* Example
#+begin_src lisp
(defparameter *url* "https://help.autodesk.com/view/ACD/2027/ENU/?guid=GUID-18ADF171-166F-4FF0-8ED6-5F83153A5649")
(defparameter *circle* (acad-help-parser:fetch-activex-class *url*))
(acad-help-parser:activex-class-name *circle*)
;; => "AcadCircle"
#+end_src
* Parser note
Version 0.2.2 uses =plump:next-element= to skip whitespace text nodes between the =dt= "Class Name" and its =dd= value.

* Printed representation

Classes print their member names grouped as methods, properties and events.
Members print their kind, name and GUID.
